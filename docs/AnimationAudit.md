# 动画缺陷排查与修复

## 范围

本轮检查了 Shell 的控制中心、状态栏、Dock 弹层、启动器、右键菜单、
快速搜索、桌面编辑入口，以及共享 Qt 控件和设置、日历、待办、音乐应用的弹层与换页。
保留了已有的 Dock 自动隐藏、窗口预览、通知列表、概览、启动器文件夹与分页动画。
系统原生文件选择器、KWin 的应用窗口特效仍由系统管理，没有覆盖用户的系统配置。

## 已修复的缺陷

| 位置 | 原有缺陷 | 修复 |
| --- | --- | --- |
| 控制中心主面板 | 单窗口改造后，协调器直接设置 `visible`，打开与关闭均无过渡 | 用 `PopupMotion` 管理生命周期；淡入淡出、缩放及朝锚点的位移，退场结束才卸载窗口 |
| 控制中心二级页面 | Wi-Fi、蓝牙、亮度、声音直接切换显隐；返回立即清空当前内容 | 请求页面和显示页面分离；只让内容退场/入场，玻璃保持不透明度、缩放与模糊区，不在切换点闪空 |
| 控制中心快速操作 | 开关状态取自窗口可见性，无法区分“正在关闭”和“仍然打开” | 按请求状态判断下一次操作；反向动画从当前进度继续，不归零、不等待旧定时器 |
| 控制中心会话页面 | 会话列表与确认框切换时，列表内容先于卡片消失 | 会话、确认占位也进入同一换页流程；确认文案保留，取消后平滑恢复会话页 |
| 控制中心按钮 | 主入口、Wi-Fi/蓝牙整块入口缺少反馈；返回、会话行缺少按压反馈 | 增加轻量悬停/按压缩放；隐藏的忙碌指示器停止旋转 |
| Wi-Fi 凭据弹层 | 关闭立刻清空网络身份、企业认证表单，退场过程发生尺寸和内容跳变 | 密码立即清除，其余呈现状态在关闭完成后清理 |
| 独立网络、蓝牙弹层 | 开关直接修改 `visible` | 使用共用 `AnimatedPopupWindow`，按 Dock 方位设置缩放原点 |
| 状态提示、传感器详情 | 状态栏和托盘提示、温度详情直接出现/消失 | 接入可反向的弹层动画；关闭时立即撤销输入区域 |
| 状态栏和 Dock 编辑器 | 编辑窗口直接显示和隐藏 | 统一入场、退场与输入生命周期 |
| Dock 音乐、天气、信息弹层 | 音乐/天气缺少动画；信息弹层用固定延迟隐藏，重开可能被旧计时器关闭 | 共用动画控制器，关闭由动画完成信号驱动；移回正在退出的信息卡可反向打开 |
| Dock 时钟详情背景 | 信息弹层有玻璃组件，但窗口未声明模糊区，导致只剩文字 | 窗口发布玻璃组件的 `blurRegion`；时钟、天气、资源详情共享该修复，退出后释放模糊区 |
| 共用右键菜单 | 默认不启用动画；子菜单切换直接替换列表 | 默认启用进出动画；父子页面采用保留旧内容的换页流程；退出期间释放键盘与鼠标输入 |
| 应用启动器 | 打开动画每次从零重启，关闭直接归零；只动画图标时，整块玻璃仍突然出现/消失 | 面板实际几何从 Dock 边缘展开/收回，居中及全屏从中心展开；玻璃区域跟随动画框，图标布局保持固定；300 ms 入场、240 ms 退场，可中途反向，退出立即撤销输入 |
| 快速搜索设置、桌面编辑 | 剪贴板设置、组件库、编辑工具栏、“打开方式”直接显隐 | 增加淡入淡出/缩放；显示意图和退出期间的可见性分离 |
| 应用对话框 | 设置、待办、日历、音乐的自绘 Dialog 没有统一动画 | 新增 `KosDialog`，统一进退场和反向切换，退出时禁用重复操作 |
| 音乐音质选择器 | 自绘 ComboBox 弹出列表无过渡 | 增加淡入淡出、微缩放；保留 Qt Popup 的交互语义 |
| 应用页面缓存 | 页面直接切换；LRU 淘汰立即销毁正在离开的页面 | 交叉淡入淡出，退出完成后再释放 Loader；离开的页面立即禁用输入 |
| 设置应用页面 | `currentPage` 立即销毁旧 Loader，标题和内容一起跳变 | 复用 `KosPageMotion`，在退场后切换显示页面；保留懒加载，提交新页时回到顶部 |
| 玻璃区域 | 模糊区域只读取局部 x/y，忽略祖先偏移和动画变换，与原生形状错位 | `SceneBounds` 跟踪祖先和变换，将区域映射到场景坐标；静止时不运行轮询定时器 |

## 动画约束

- 普通 Shell 弹层沿用 150 ms 入场、140 ms 退场；大尺寸启动器使用 300/240 ms；页面过渡使用现有主题的快速/普通时长。
- `KosPageMotion` 只在旧页内容完全退出后提交页面，不让两层控制中心玻璃互相覆盖。
  卡片根节点始终保留玻璃，仅内容容器跟随换页进度；默认内容别名位于卡片根节点，
  确保调用者声明的按钮和文字确实进入动画容器，而不是绕过它成为玻璃的兄弟节点。
- 关闭同步清空逻辑子菜单，显示快照独立保留，避免下次点击被旧状态吞掉。
- 独立应用的对话框、页面缓存和设置换页遵循 `AppTheme.reduceMotion`。
- 输出丢失时，通用窗口立即停止动画；普通关闭才保留退出画面。
- KWin 仍负责原生玻璃绘制；这里同步其几何区域与 Qt 内容的缩放、位移。
  当前形状协议没有逐卡片透明度字段，因此不声称实现原生玻璃材质的逐像素 alpha 渐变。
  本轮没有修改或重装 KWin 插件，也没有改动窗口管理器特效配置。

## 验证

新增测试：

- `python3 tests/popup-motion/run.py`：真实 Wayland/Quickshell 下验证控制中心主面板、
  二级页、返回、连续更改目的页、换页途中关闭重开、会话确认取消、菜单、启动器退出，
  以及带祖先缩放/平移的模糊区域。逐帧检查换页期间玻璃根节点不淡出、窗口模糊区不清空，
  验证卡片默认内容实际进入动画容器，以及时钟/天气/资源详情始终发布模糊区。
  启动器另覆盖底部、宽底部、左/右侧、居中、全屏六种布局的真实玻璃几何、固定内容尺寸、锚点与反向动画。
- `qmltestrunner -input tests/interaction-controls/tst_motion.qml`：验证共享对话框
  的反向动画与退出禁用、页面缓存延迟淘汰、减少动态效果、设置应用的连续换页。
- 对应 CTest 项为 `kos-ui.popup-motion` 和 `kos-ui.shared-motion`。

同时运行了视觉契约、控制中心状态契约、页面缓存策略、既有交互运行测试、
桌面组件体验测试、音乐菜单测试、设置控件测试，并构建 `kos_ui`。
真实 Shell 通过 `control-center.toggle` IPC 快速反复开关，启动达到 `Configuration Loaded`，
没有新增 QML 类型错误或绑定循环。

现有 `tests/liquid-glass-panel/run.mjs` 在进入运行阶段前，有一个与本轮无关的静态断言失败：
它要求 Dock 半径写成 `radius: dockContainer.pillRadius`，实际代码已支持
`root.stretched ? 0 : dockContainer.pillRadius`。本轮未修改该测试或 Dock 半径。

Shell 源码模式重载后生效；使用嵌入 QML 的独立应用需要重新构建。
