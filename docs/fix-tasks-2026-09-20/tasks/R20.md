## 问题
- `apps/music/qml/Main.qml:578` `onTextChanged: music.setSearch(text)` → `TrackListModel::rebuild()`（`TrackListModel.cpp:146-207`）每键入做全库 `localeAwareCompare` 排序 + `beginResetModel/endResetModel` → 全 delegate 销毁重建 + Artwork 重载。无 debounce。
- `apps/music/src/MusicController.cpp:98-123` — 构造期 UI 线程同步 `m_database.open()` + `refreshLibrary()`（`allTracks` 全表读入）+ `refreshQueueModel()` + `new MprisService`。`Main.qml:155` 里 `MusicController{}` 是 QML 树一部分 → 首帧前全跑完，大库下首帧延迟明显。
- `apps/music/src/MusicController.cpp:870` — `findTrack()` 线性扫 `m_tracks`，`currentTitle/Artist/ArtworkUrl/durationMs` 每属性一次 O(n)。
- `apps/music/qml/TrackListView.qml:222` — 每 delegate 一个完整 `Menu`（8 MenuItem）。

## 改动点
- 搜索加 ~300ms debounce；rebuild 尽量增量而非全 reset。
- `MusicController` ctor 只建空对象，`QTimer::singleShot(0)`/工作线程 open+load，ready 后 `libraryChanged`。
- `findTrack` 建 `QHash<qint64,int>` 索引。
- `TrackListView` 的 Menu 改 ListView 级单例 + `popup(row,trackId)`。
