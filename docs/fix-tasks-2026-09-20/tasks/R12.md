## 问题
- `ControlCenterService.qml:416-418` — `Quickshell.execDetached(["qdbus6","org.kde.kglobalaccel",...])` 作 `nightlight.toggle` 失败 fallback（文档明文禁止 qdbus6）。
- `DesktopAppLauncher.qml:48-65` — `sh -c` 探测 PATH 启动 kos-settings。
- `TrayNotificationBridge.qml:67-76`、`DeskCenterWindow.qml:175` — QML 直接 spawn `notify-send`；且 `TrayNotificationBridge._sender` 单实例 Process 复用有竞态（前次未退出时改写 command 会丢通知/发错）。
- `AppActionService.qml:33-43,101-107` — `execDetached`/`entry.execute()` 启动（可选并入）。

## 改动点
- nightlight 失败 fallback 改经 daemon（kwinrc 写+reconfigure）或新增 `nightlight.invoke-shortcut` op；失败时显示 `lastSessionError`。
- settings 启动改 R10 `settings.launch` op（固定 argv），删 `sh -c` PATH 探测。
- notify-send 改 R10 `notify` op 或内部 NotificationServer；`TrayNotificationBridge` 每次 createObject 一次性 Process 或直接走 op，消竞态。

## 验证
- `grep -rn "qdbus6\|notify-send\|execDetached\|\"sh\"" shell/` 仅剩白名单命中。
- nightlight 切换、托盘通知、settings 启动实测正常。

## 审查要点
- fallback 删除后失败路径仍有用户可见提示。
- 通知内容含特殊字符时经 op 传递正确。
