## 问题
`PlatformServer.cpp:3434-3445, 3499-3505` — `network.connect`/`network.connect-enterprise` 把 `password`/`802-1x.password` 作为 `nmcli` argv 传递。进程命令行 `ps`/`/proc/*/cmdline` 对同机所有用户可读 → 同机信息泄露。且 `:3449-3529` 是 4 段串行 `nmcli` 进程（各 ≤10-40s）。

## 改动点
- 改走 NetworkManager D-Bus `AddConnection`/`Update`，把密码放进 settings dict，不进 argv。
- 顺带把 4 段串行 nmcli 收敛（可结合 R8 的异步化思路）。

## 验证
- 连接后 `ps`/`/proc/*/cmdline` 不含密码明文。
- WPA/WPA2-Enterprise 连接实测成功。

## 审查要点
- settings dict 结构与 NM API 匹配（802-1x/wireless-security 字段）。
- 错误路径不泄露密码到日志。
