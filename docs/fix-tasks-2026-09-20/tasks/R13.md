## 问题
`platform/src/daemon/Shortcuts.cpp:183-188` — `QProcess::startDetached("/bin/sh", {"-c", exec})` 处理 kglobalaccel 动作：
- `sh -c` 路径未加引号 → 含空格路径失效；
- exec 字符串来自 `shortcuts.apply` JSON payload，daemon 对 socket 仅 0600（同用户），非跨用户提权，但 Exec 是任意 shell 命令，**无 allowlist**——`platform.v1.md` 声称 "daemon validates"，实际只校验 id/combo 非空与去重，没校验 exec 形态。

## 改动点
- exec 改 argv 数组 `startDetached(program, args)`（修空格路径 + 去 shell 注入面）。
- `applyShortcutSet` 对 exec 加前缀白名单（`qs -c kos ipc call` / `qs --path <dir> ipc call` + 已注册 target/action 名），拒绝其它并记录。
- 同步 `platform.v1.md` 的校验承诺。

## 验证
- 含空格路径的全局快捷键可用。
- 非白名单 payload 被拒并写日志。

## 审查要点
- 白名单是否覆盖现有全部合法快捷键（避免误拒）。
- argv 拆分与 quoting 正确。
