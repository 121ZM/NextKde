## 问题
`PlatformServer.cpp:1507-1620` — `network.refresh` 在主事件循环串行做 N+1 个同步 D-Bus：`GetDevices` 一次 + 每台设备 `nmGetAll` + 活跃连接/IP4Config/AccessPoint 各一次。每设备 ~3-4 个 2s 上限往返，全在 GUI 线程；设备多/NM 慢时单次请求阻塞 daemon 数秒。15s TTL 缓存缓解频率但每次 miss 全阻塞。

## 改动点
- 改 `QDBusPendingCall`/`asyncCall` 链，或挪到 worker 线程（注意 `QDBusConnection` 不可跨线程共享，worker 内需 `connectToBus`）。
- 聚合所有设备结果后一次性 respond。
- 保留 15s TTL 缓存与 per-op in-flight 去重。

## 验证
- 多设备/慢 NM 下 network.refresh 不阻塞其它请求。
- 返回数据结构与原来一致（ssid/signalStrength/ipv4 等字段）。

## 审查要点
- asyncCall 回调乱序/部分失败的聚合正确性。
- worker 线程 QDBusConnection 的创建/销毁。
